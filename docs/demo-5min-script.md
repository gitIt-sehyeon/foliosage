# FolioSage 5-Minute Demo Script

## One-Sentence Message

FolioSage turns scattered project files into an evidence-backed portfolio that can be organized, reviewed, published, and questioned with AI.

## 5-Minute English Script

### 0:00-0:30 Opening

Hi everyone, my name is sehyeon, and today I will give a quick demo of FolioSage.

FolioSage is an AI portfolio platform for creators, developers, designers, and job seekers. The main idea is simple: instead of showing only a polished final result, FolioSage helps users prove how their work was made with real evidence files.

In this demo, I will show four parts: the creator dashboard, evidence organization, AI portfolio review, and the public portfolio with visitor AI chat.

### 0:30-1:00 Problem

Most portfolio websites are static. They show screenshots, descriptions, and final outputs, but reviewers still have important questions.

For example: What exactly was the creator's role? Which files prove the process? What trade-offs were made? And can a visitor ask questions without opening every file manually?

FolioSage solves this by connecting project files, AI-generated storytelling, review feedback, public sharing, and evidence-based AI Q&A in one workflow.

### 1:00-1:40 Dashboard

First, this is the creator dashboard.

Here, the user can see all portfolios, how many are published, and how many evidence files have been uploaded. Each portfolio card shows whether the story is ready, whether AI review is complete, and whether the portfolio is published.

This matters because the dashboard is not just a file list. It shows the readiness of each portfolio, so the creator knows what still needs to be done before sharing it with a reviewer, recruiter, or judge.

Now I will open one portfolio.

### 1:40-2:30 Evidence Organization

This is the evidence organization screen.

The user can upload many types of project files, such as PDFs, images, presentation decks, source code, ZIP files, planning documents, and final outputs.

FolioSage organizes the files into four evidence lanes: System, Visual, Document, and Deliverable.

The creator can move files manually, upload directly into a lane, or ask AI to reclassify the files. If the creator wants to preserve their own decision, they can manually lock the category.

Each file also keeps trust signals, such as metadata, timestamp, SHA-256 hash, and a VaultSage file ID. So the portfolio is backed by concrete source files, not only written claims.

### 2:30-3:15 Portfolio Story

Next, FolioSage generates a portfolio story from the uploaded evidence.

The story is structured into Summary, Role, Problem, Solution, and Impact. This format is useful because it matches how people usually explain work in interviews, judging sessions, and project reviews.

FolioSage also generates evidence highlights and likely interview questions. So the creator gets not only polished writing, but also preparation material for defending the project.

The important point is that the AI draft stays editable. The creator remains in control, while AI helps turn scattered files into a clear explanation.

### 3:15-4:00 AI Portfolio Review

Now I will show the AI Portfolio Review.

Here, the system generates defense questions based on the portfolio. The creator answers the questions, and AI reviews the answer using the uploaded evidence files.

The review returns feedback, cited evidence files, missing proof alerts, and a scorecard across multiple categories.

This is different from a generic chatbot because the feedback is grounded in the creator's actual files. If a claim is not supported by evidence, FolioSage can point out what proof is missing.

This helps the creator improve the portfolio before sending it to someone else.

### 4:00-4:40 Public Portfolio

After the portfolio is ready, the creator can publish a public share link.

This public page does not require login. Visitors can read the story, browse the evidence grid, preview or download files, and see review information.

The most important feature here is the visitor AI guide. A visitor can ask questions like, "What was the creator's role?", "Which files best prove the final result?", or "What should be improved from a judge's perspective?"

The AI answers using the shared portfolio evidence, so the public page becomes interactive instead of static.

### 4:40-5:00 Closing

To summarize, FolioSage turns a portfolio into an evidence-backed AI workflow.

It helps creators organize real project files, generate an interview-ready story, review their answers with AI, and publish a public portfolio where visitors can ask evidence-grounded questions.

That is the end of my demo. Thank you for watching, and I am happy to answer any questions.

## Short Backup Version

Hi everyone, today I will demo FolioSage, an AI portfolio platform that turns scattered project files into an evidence-backed public portfolio.

The problem is that most portfolios show only final results. They do not clearly prove the creator's role, process, decisions, or supporting evidence.

FolioSage solves this in one workflow. First, the creator uploads project files like PDFs, images, slides, code, ZIP files, and final outputs. Then the files are organized into evidence lanes: System, Visual, Document, and Deliverable. The creator can organize manually or use AI reclassification.

Next, FolioSage generates a structured portfolio story with Summary, Role, Problem, Solution, and Impact. It also creates evidence highlights and likely interview questions.

After that, the creator can run AI Portfolio Review. The system asks defense questions, reviews the creator's answers, cites evidence files, shows missing proof, and provides a scorecard.

Finally, the creator publishes a public link. Visitors can read the story, inspect evidence files, and ask the AI guide questions grounded in the shared files.

In short, FolioSage changes a portfolio from a static showcase into an interactive, evidence-backed explanation of real work. Thank you.
