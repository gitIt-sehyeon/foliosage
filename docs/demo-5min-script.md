# FolioSage 5-Minute Demo Script

## One-Sentence Message

FolioSage turns scattered project files into an evidence-backed portfolio that can be organized, reviewed, published, previewed, and questioned with AI.

## 5-Minute English Script

### 0:00-0:30 Opening

Hi everyone, my name is sehyeon, and today I will give a quick demo of FolioSage.

FolioSage is an AI portfolio platform for creators, developers, designers, and job seekers. Instead of showing only a polished final result, it helps users prove how their work was made with real evidence files.

In this demo, I will show the dashboard, public profile, evidence organization, AI review, and the public portfolio with file preview, project map, and visitor AI chat.

### 0:30-1:00 Problem

Most portfolio websites are static. They show screenshots and final outputs, but reviewers still have important questions.

For example: What exactly was the creator's role? Which files prove the process? What trade-offs were made? And can a visitor ask questions without opening every file manually?

FolioSage connects project files, AI-generated storytelling, AI review, public sharing, file preview, and evidence-based Q&A in one workflow.

### 1:00-1:35 Dashboard and Public Profile

First, this is the creator dashboard.

Here, the user can see all portfolios, publish status, uploaded file count, story readiness, and AI review status.

So the dashboard shows what still needs to be done before sharing with a reviewer, recruiter, or judge.

The creator can also share a public profile link. A recruiter can see multiple public portfolios, public stats, and AI review badges in one place.

Now I will open one public portfolio from this profile. This is the entry point I would give to an interviewer.

### 1:35-2:25 Evidence Organization

Before we inspect the public page, I will switch back to the creator side and show how this portfolio is built.

The user can upload PDFs, images, presentation decks, source code, ZIP files, planning documents, and final outputs.

FolioSage organizes files into four evidence lanes: System, Visual, Document, and Deliverable.

The creator can move files manually, upload into a lane, or ask AI to reclassify files.

Each file keeps trust signals: metadata, timestamp, SHA-256 hash, and a VaultSage file ID. So the portfolio is backed by source files, not only written claims.

I can also show the AI folder structure. This is separate from the four manual categories. VaultSage generates a project map, and FolioSage displays it as an interactive graph.

### 2:25-3:05 Portfolio Story

Next, FolioSage generates a portfolio story from the uploaded evidence.

The story is structured into Summary, Role, Problem, Solution, and Impact, matching how people explain work in interviews and judging sessions.

FolioSage also generates evidence highlights and likely interview questions, so the creator gets both writing and preparation material.

The AI draft stays editable. The creator remains in control, while AI turns scattered files into a clear explanation.

### 3:05-3:45 AI Portfolio Review

Now I will show the AI Portfolio Review.

Here, the system generates defense questions. The creator answers, and AI reviews the answer using the uploaded evidence files.

The review returns feedback, cited files, missing proof alerts, and a scorecard.

This is not generic chat. If a claim is not supported, FolioSage can point out what proof is missing.

### 3:45-4:45 Public Portfolio

After the portfolio is ready, the creator publishes it to the public profile.

Visitors do not need to log in. They can read the story, browse evidence, preview or download files, inspect the project map, and see review information.

For file preview, PDFs and images open directly. Word, PowerPoint, Excel, text, and Markdown are rendered as PNG previews. Unsupported files still have a download fallback.

The Project map gives visitors another way to understand the evidence structure, not just a flat file grid.

The visitor AI guide can answer questions like, "What was the creator's role?", "Which files prove the result?", or "What should be improved?"

The AI answers from the shared portfolio evidence, so the public page becomes interactive instead of static.

### 4:45-5:00 Closing

To summarize, FolioSage turns a portfolio into an evidence-backed AI workflow.

It helps creators organize files, generate an interview-ready story, review answers with AI, and publish a portfolio where visitors can inspect evidence and ask grounded questions.

That is the end of my demo. Thank you for watching, and I am happy to answer any questions.

## Short Backup Version

Hi everyone, today I will demo FolioSage, an AI portfolio platform that turns scattered project files into an evidence-backed public portfolio.

The problem is that most portfolios show only final results. They do not clearly prove the creator's role, process, decisions, or supporting evidence.

FolioSage solves this in one workflow. First, the creator uploads project files like PDFs, images, slides, code, ZIP files, and final outputs. Then the files are organized into evidence lanes: System, Visual, Document, and Deliverable. The creator can organize manually or use AI reclassification. FolioSage also shows a VaultSage-generated project map as an interactive graph.

Next, FolioSage generates a structured portfolio story with Summary, Role, Problem, Solution, and Impact. It also creates evidence highlights and likely interview questions.

After that, the creator can run AI Portfolio Review. The system asks defense questions, reviews the creator's answers, cites evidence files, shows missing proof, and provides a scorecard.

Finally, the creator publishes the portfolio to their public profile. Instead of sending only one project URL, the creator can share a profile link where visitors can browse multiple public portfolios, open one project, preview or download evidence files, inspect the project map, and ask the AI guide questions grounded in the shared files.

In short, FolioSage changes a portfolio from a static showcase into an interactive, evidence-backed explanation of real work. Thank you.
